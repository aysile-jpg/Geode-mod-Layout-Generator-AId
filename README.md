# Layout AI (Geode mod)

Сборка .geode:
- Локально: `geode build` -> файл `build/yourname.layout-ai.geode`
- Через GitHub: залей папку в репозиторий -> Actions -> Build Geode Mod -> Artifacts -> "Build Output"

Установка: положи .geode в `Geometry Dash/geode/mods/` и перезапусти игру.
В настройках мода укажи API Key (и при желании URL/модель).
